Project Name : Superstore sales analysis

1. Project Overview

The Superstore Sales Analysis project is designed to analyze retail sales data and extract meaningful business insights using SQL. The dataset contains information related to customer orders, sales, profit, discounts, shipping details, product categories, and customer segments.

The objective of this project is to perform data analysis, identify business trends, optimize reporting, and improve decision-making through SQL queries, views, CTEs, stored procedures, triggers, indexes, and performance optimization techniques.
